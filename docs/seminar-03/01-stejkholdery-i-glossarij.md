# Стейкхолдеры, предметная область, глоссарий

NeuroGateway — шлюз к языковым моделям. Клиентское приложение говорит с одним HTTP API в форме Chat Completions. Шлюз выбирает провайдера, считает токены и списывает баланс. Промпты по умолчанию не хранятся.

## Стейкхолдеры

| Роль | Цель | Интерес к системе | Влияние |
|---|---|---|---|
| Разработчик-одиночка | Подключить модель за минуты и платить в рублях | Простой ключ, предсказуемая цена, живой контракт | Высокое: без первого успешного запроса продукт не активируется |
| Стартап | Не держать договоры с каждым провайдером | Общий баланс, лимиты по ключам, смена модели без переписывания клиента | Высокое: основной объём токенов |
| IT-компания / интегратор | Встроить модели в продукт заказчика и получить закрывающие документы | Организации, роли, счета, акты | Высокое на фазе юрлиц, на MVP — среднее |
| Data-инженер | Гонять запросы пакетами и видеть расход | Статистика, журнал без текста промпта, квоты | Среднее |
| Пользователь no-code (n8n, Make) | Вызвать модель из сценария без SDK | Тот же HTTP-контракт и ключ | Среднее |
| Провайдер модели | Отдавать ответы по своему API и получать оплату от шлюза | Стабильный адаптер, соблюдение ToS | Высокое: нет провайдера — нет ответа |
| Эквайринг | Принять платёж физлица по 54-ФЗ | Корректный чек и сумма | Низкое до реальных платежей, дальше высокое |
| Команда NeuroGateway | Довести фазу и не потерять деньги на расхождении ledger | Наблюдаемость, hold до запроса, сверка usage | Высокое |

Преподаватель принимает учебный результат, но не является пользователем шлюза и в контекст системы не входит.

## Предметная область

Клиент создаёт учётную запись, выпускает API-ключ и пополняет баланс. Приложение клиента шлёт запрос с именем модели. Шлюз проверяет ключ и лимиты, резервирует сумму на балансе, переписывает запрос в контракт выбранного провайдера, возвращает ответ и фиксирует фактические токены проводкой. Если провайдер недоступен и у клиента разрешён запасной маршрут, шлюз повторяет запрос у другого провайдера в пределах той же резервации.

Граница MVP, Beta и GA задаётся в PRD (`ID24_API-7`). В этот контур не входят собственные веса моделей и обучение.

## Глоссарий

| Термин | Смысл |
|---|---|
| Провайдер | Внешний API модели: OpenAI, Anthropic, Gemini, DeepSeek, YandexGPT, GigaChat и любой OpenAI-совместимый endpoint |
| Адаптер | Код, который переводит канонический запрос в контракт провайдера и обратно |
| Модель | Имя, которое видит клиент. Одно имя может смотреть на несколько endpoint провайдеров |
| Каноническая схема | Единый JSON запроса и ответа шлюза, задача `ID24_API-24` |
| Генерация | Один принятый вызов, у которого есть `X-Generation-Id` |
| Hold | Резерв суммы на балансе до вызова провайдера. Без успешного hold запрос к провайдеру не уходит |
| Ledger | Двойная запись в PostgreSQL: резерв, списание, возврат остатка резерва |
| Usage | Факт токенов, модели, провайдера, задержки и стоимости. Текст промпта в usage не входит |
| No-log | Режим по умолчанию: текст запроса и ответа не пишется |
| Ключ | Секрет клиента. Показывается один раз при выпуске, в хранилище лежит не в открытом виде |
