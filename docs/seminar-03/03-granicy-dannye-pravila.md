# Границы, источники данных, правила

## Граница системы

Внутри NeuroGateway: учётные записи и ключи, каталог моделей, gateway, адаптеры, ledger, журнал usage, личный кабинет, админка цен.

Снаружи:

| Внешняя система | Зачем | Кто владеет данными на той стороне |
|---|---|---|
| API провайдеров моделей | Ответ модели | Провайдер |
| Эквайринг (карты РФ, СБП, SberPay) | Пополнение физлица после MVP | Банк / платёжный провайдер |
| Курс ЦБ РФ | Пересчёт валютной себестоимости в рубли | Банк России |
| Почта и Telegram | Транзакционные уведомления | Оператор канала |
| OAuth: Яндекс ID, VK ID, Google, GitHub, Telegram | Вход без пароля, после MVP | Провайдер входа |

На MVP снаружи обязательны только провайдеры моделей. Эквайринг и OAuth в Release 0.5 не входят: пополнение — заглушка, вход — email и пароль.

## Каталог источников

| Источник | Формат | Частота | Объём на MVP | Владелец | Доступ |
|---|---|---|---|---|---|
| Запрос клиента `POST /v1/chat/completions` | JSON, OpenAI-совместимый | На каждый вызов | До 1 МБ тела, лимит задаётся в `ID24_API-53` | Клиент | HTTPS, заголовок с ключом |
| Ответ провайдера | JSON или SSE конкретного провайдера | На каждый вызов | Поток до лимита длительности стрима | Провайдер | HTTPS из адаптера, ключ провайдера из секрет-хранилища |
| Каталог моделей | Строки PostgreSQL: имя, алиас, endpoint, возможности, цена | Реже изменений, чтение на каждый запрос из кэша | Десятки моделей, не миллионы | Ерофеев Илья как владелец каталога в админке | Запись из админки, чтение gateway |
| Проводка ledger | Строки двойной записи в PostgreSQL | На каждый успешный и отменённый вызов | Одна генерация — резерв, списание, при необходимости возврат остатка | Сервис биллинга | Транзакция PostgreSQL до ответа клиенту о списании |
| Usage | Событие: id генерации, ключ, модель, провайдер, prompt/completion tokens, latency_ms, сумма в минимальных единицах | На каждую генерацию | Сотни тысяч строк за семестр на учебном контуре, не текст промпта | Сервис биллинга | Очередь из gateway в worker, витрина в ClickHouse |
| Курс ЦБ | Число RUB за единицу валюты себестоимости, дата курса | Не реже раза в сутки | Одна строка на валюту в день | Деревцов Андрей ведёт правило свежести, импорт — задача `ID24_API-97` | HTTP API ЦБ |
| Учётная запись и ключ | PostgreSQL, секрет ключа не в открытом виде | На регистрацию и ротацию | Единицы пользователей в альфе | Сервис пользователей | Только backend |
| Журнал промптов | Текст | Выключен | 0 по умолчанию | Клиент включает явно | Отдельное хранилище, не usage |

Каталог не сводится к именам файлов: у каждого источника есть формат, частота, объём, владелец и способ доступа.

## Правила и ограничения

1. Нет успешного hold — нет вызова провайдера.
2. Цена токена фиксируется в момент hold и не меняется задним числом для этой генерации.
3. Текст промпта и ответа не пишется, пока клиент явно не включил сохранение.
4. Ключ провайдера и секрет ключа клиента не попадают в usage, логи приложения и ответы API.
5. Запасной провайдер используется только если модель и возможности запроса это позволяют и клиент не запретил маршрут.
6. Данные запросов, которые система всё же хранит, остаются в контуре, выбранном для 152-ФЗ. Учебный stage не используется как прод с реальными персональными данными клиентов.
7. Генерация без проводки дольше 60 секунд после ответа клиенту считается дефектом сверки, а не нормальным лагом.
