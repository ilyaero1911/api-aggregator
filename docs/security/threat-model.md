# Threat model

Срез STRIDE по шлюзу, биллингу и ключам. Это документ, не пентест.

| Угроза | Класс | Что уже есть | Куда смотреть |
| --- | --- | --- | --- |
| Кража API-ключа | Spoofing | Секрет хранится как SHA-256, в списке ключей его нет, отзыв чистит кэш | ID24_API-114, ID24_API-48 |
| Обход списания гонкой | Tampering | Повтор generation и Idempotency-Key не делают второе списание | ID24_API-205, ID24_API-66 |
| SSRF через адрес картинки | Tampering | Картинка влияет только на фильтр эндпоинта. Отдельной загрузки URL шлюз не делает | ID24_API-88 |
| Инъекция в промпт | Tampering | Явная попытка сбросить инструкции режется до провайдера | ID24_API-175 |
| Чужой generation или ключ | Information disclosure | Запись generation отдаётся только своему аккаунту | ID24_API-55 |
| Утечка ключа провайдера | Information disclosure | Ключ провайдера лежит в конверте, дамп без открытого текста | ID24_API-169 |
| Исчерпание лимита одним клиентом | Denial of service | Окно RPM, доля слотов провайдера, отдельная квота :free | ID24_API-123, ID24_API-125, ID24_API-127 |
| Накрутка бонуса | Repudiation | Бонус и кошелёк разведены в ledger, чужой hold не захватывается | ID24_API-205 |

Высокий риск без отдельной новой карточки не оставлял: каждая строка ссылается на уже заведённую задачу. Боевой KMS, общий Redis и журнал личного кабинета в этот срез не входят.
