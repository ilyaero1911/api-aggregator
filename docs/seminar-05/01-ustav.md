# Устав проекта v1.0

Устав фиксирует рамку работы. Список функций, пороги и критерии приёмки лежат в требованиях v1.0 и здесь не повторяются.

## Цель и ценность

Собрать NeuroGateway как учебный, но цельный продукт: клиент подключает один ключ и получает ответ языковой модели с понятным списанием в рублях. Ценность для пользователя — не вести отдельный контракт и кабинет на каждого провайдера. Ценность для команды — довести вертикальный срез до проверяемого Release 0.5, а не до набора несвязанных прототипов.

## Ограничения

- Четыре человека, проект идёт вместе с остальной учёбой. Ёмкость спринта — две недели, состав набирает тимлид.
- Боевые платежи, юрлица и обещание доступности 99,9% в этот устав не входят. Это критерии более поздних фаз из `ID24_API-10`.
- Ключи боевых провайдеров и персональные данные посторонних людей на учебный stage не кладём.
- Секреты и текст промптов не пишем в журнал usage. Это ограничение проекта, не деталь одной задачи.

## Допущения

- На срез хватит mock-провайдера и одного OpenAI-совместимого адаптера. Три боевых провайдера — критерий фазы MVP, он может выйти за Release 0.5, если срез ещё не стоит на stage.
- Пополнение на срезе — заглушка с проводкой.
- Спринт 0 заканчивается 05.10.2026 и закрывает фундамент: регламент, PRD, схему, OpenAPI, NFR, каркас репозитория. Код gateway в спринт 0 не обещан.
