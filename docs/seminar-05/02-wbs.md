# Содержание семестра и WBS

## Что входит в семестр

Release 0.5 — вертикальный срез на stage, а не каталог всех эпиков.

Срез считается вышедшим, если одновременно:

1. Есть вход по email, выпуск ключа и заглушка пополнения с проводкой.
2. `POST /v1/chat/completions` без стрима возвращает ответ mock-провайдера или одного боевого OpenAI-совместимого адаптера.
3. Пустой баланс не вызывает провайдера.
4. Успешный ответ оставляет одну проводку и запись usage без текста промпта.
5. Сценарии US-04 и US-05 из требований v1.0 проходят на stage.
6. Сервис поднимается из docker-compose по инструкции в репозитории.

В этот семестр также входит фундамент, без которого срез нельзя принять: регламент, PRD, C4, ADR, OpenAPI, ERD, NFR, тестовая стратегия.

Не входит в Release 0.5, даже если эпик уже заведён: SSE, fallback, боевой эквайринг, организации, личный кабинет со статистикой, пентест, GA.

## WBS

Декомпозиция по результатам, не по отделам.

1. Управление
   1.1. Регламент и доска — `ID24_API-5`
   1.2. PRD и границы фаз — `ID24_API-7`, `ID24_API-10`
   1.3. Устав, WBS и эта дорожная карта
2. Требования и архитектура

   2.2. OpenAPI — `ID24_API-25`

   2.4. NFR — `ID24_API-27`
3. Данные
   3.1. ERD и миграции — `ID24_API-26`
   3.2. Ledger и hold — `ID24_API-93`, `ID24_API-95`
   3.3. Usage без текста промпта — `ID24_API-129`, `ID24_API-131`
4. Разработка
   4.1. Каркас gateway — `ID24_API-47`
   4.2. Ключ и аутентификация вызова — `ID24_API-48`, `ID24_API-114`
   4.3. Метод chat completions без стрима — `ID24_API-49`
   4.4. Один адаптер и mock — `ID24_API-74` или `ID24_API-69`, `ID24_API-185`
   4.5. Заглушка пополнения — `ID24_API-98`
5. Тестирование

   5.2. Сверка биллинга — `ID24_API-182`
