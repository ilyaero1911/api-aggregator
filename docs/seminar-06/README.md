## Шкалы

Вероятность P на оставшуюся часть первого семестра: 1 — маловероятно (до 10%), 2 — возможно (10–30%), 3 — вероятно (30–50%), 4 — весьма вероятно (50–80%), 5 — почти неизбежно (от 80%). Проценты — экспертная оценка команды, не статистический прогноз.

Влияние I: 1 — до двух часов исправления без изменения результата; 2 — до одного рабочего дня; 3 — до трех дней либо деградация части сценариев; 4 — задержка контрольной точки или недоступность основного сценария; 5 — нарушение целостности баланса, изоляции аккаунтов, раскрытие секретов либо невозможность выпустить срез. При нескольких последствиях берется максимальное.

Приоритет S = P × I: 1–4 низкий, 5–9 средний, 10–15 высокий, 16–25 критический. Любой риск с I = 5 рассматривается на планировании независимо от S.

## Воспроизведение

Из корня репозитория, Python 3.10+ и стандартная библиотека:

```sh
python3 tools/check_risks.py
python3 tools/check_risks.py --render
python3 -m unittest discover -v
```

Первая команда проверяет полноту реестра, шкалы, приоритеты, даты, три индикатора у каждого риска и связь высоких рисков с задачами. Вторая дополнительно обновляет SVG. Зеленые пять тестов среза подтверждают только уже описанные сценарии; они не означают снятие всех рисков биллинга.
