# Нефункциональные требования и требования к данным

Числа ниже — порог Release 0.5 на учебном stage, не обещание GA. GA в дорожной карте держит доступность 99,9% (`ID24_API-10`). Исполнитель сводной задачи по SLO — Деревцов Андрей, `ID24_API-27`.

## Нефункциональные

| ID | Класс | Порог | Как проверить |
|---|---|---|---|
| NFR-01 | Производительность | Накладные расходы шлюза без времени провайдера: p95 не больше 80 мс на `POST /v1/chat/completions` без стрима при 20 параллельных запросах в течение 5 минут | Замер k6, задача `ID24_API-181`, провайдер заменён mock из `ID24_API-185` |
| NFR-02 | Надёжность | Потерянная проводка: 0 генераций, у которых клиент получил 200, а через 60 с в ledger нет списания или снятия hold | Сверка в тесте `ID24_API-182` |
| NFR-03 | Доступность | На stage за календарный месяц доля успешных health-check раз в минуту не ниже 99,0%. Окно плановых работ в замер не входит, если оно объявлено заранее | Проверка серии health-check |
| NFR-04 | Восстановление | RPO ledger = 0: проводка фиксируется коммитом PostgreSQL до того, как клиенту подтверждено списание. RTO gateway на stage = 15 минут до восстановления health после падения одного экземпляра | Упражнение: остановить экземпляр и поднять его из docker-compose |
| NFR-05 | Безопасность | Секрет ключа клиента и ключ провайдера не встречаются в теле ответа, в usage и в логе приложения. Транспорт снаружи — TLS | Просмотр фикстур логов и ответа в тесте выпуска ключа |
| NFR-06 | Сопровождаемость | Изменение цены модели не требует правки кода адаптера: цена читается из каталога | Регрессия: смена цены в каталоге меняет следующую проводку |

## Требования к данным

| ID | Поле или набор | Правило | Проверка |
|---|---|---|---|
| DR-01 | Usage | Обязательны: id генерации, id ключа, модель, провайдер, prompt_tokens ≥ 0, completion_tokens ≥ 0, latency_ms ≥ 0, сумма в минимальных единицах. Текста промпта нет | Схема события и негативный тест на лишнее поле |
| DR-02 | Полнота | 100% ответов 200 имеют usage и ровно одну проводку списания | Сверка за прогон |
| DR-03 | Точность токенов | prompt_tokens и completion_tokens в usage равны числам, которые адаптер отдал из ответа провайдера. Расхождение больше 0 — дефект | Контрактный тест адаптера |
| DR-04 | Свежесть курса | Для валютной себестоимости в проводке дата курса ЦБ не старше 24 часов на момент hold | Запрос с курсом возрастом 25 часов отклоняется или помечается блокировкой биллинга |
| DR-05 | Пропуски | В usage допустимых пустых обязательных полей нет. Необязательное поле `finish_reason` может быть пустым | Валидация схемы, доля пустых обязательных полей = 0 |
| DR-06 | Хранение | Usage и проводки хранятся 365 дней. Текст промпта не хранится, срок для него не задаётся, пока клиент не включил отдельный режим | Политика таблицы и отсутствие колонки текста в usage |
| DR-07 | Формат запроса | Тело `POST /v1/chat/completions` — JSON канонической схемы. Иной `Content-Type` получает 415 | Негативный запрос |
| DR-08 | Объём | Тело запроса больше лимита из `ID24_API-53` не уходит провайдеру и не создаёт hold | Запрос сверх лимита |
