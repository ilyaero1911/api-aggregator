# Соглашение об обработке данных

Шаблон для корпоративного клиента. Это не подписанный договор.

Исполнитель обрабатывает метаданные запроса, чтобы списать стоимость и разобрать сбой: идентификатор, аккаунт, модель, провайдер, объём токенов, время. Текст промпта и ответа по умолчанию не сохраняется.

Клиент не передаёт через шлюз специальные категории данных, если стороны отдельно не согласовали другой режим. Утечка секрета в промпте режется до отправки провайдеру, когда срабатывает проверка маски.

Срок хранения метаданных и порядок удаления согласуются в договоре. До этого момента действует правило no-log из docs/policy/retention.md.

Запросы по соглашению идут на тот же адрес, что и жалобы в docs/policy/abuse.md.
