# Хранение запросов

По умолчанию шлюз не пишет текст промпта и ответа. В записи generation остаются идентификатор, аккаунт, модель, провайдер, счётчики токенов и причина маршрута.

Журнал биллинга хранит проводки, а не текст сообщений. Включение хранения текста — отдельное согласие, в этом срезе его нет.

У каждого провайдера в каталоге есть поле политики данных. Запрос с `provider.data_collection = deny` не идёт на эндпоинт, который данные забирает.

Срок оперативной записи — жизнь процесса. Отдельной выгрузки в ClickHouse нет.
