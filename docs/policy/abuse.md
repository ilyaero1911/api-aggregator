# Жалобы и блокировка

Адрес для жалобы в этом срезе — запись через POST /v1/abuse. Отдельного почтового ящика на бою нет.

Поля: account, key, reason. Запись попадает в журнал. Если передан секрет ключа, ключ отзывается сразу и кэш ключа сбрасывается.

Срок реакции, который закладываем для боевого процесса: подтвердить получение в тот же рабочий день, заблокировать ключ при явной жалобе сразу, разобрать аккаунт на следующий рабочий день. Здесь проверяется только сама блокировка.

Отказ модерации до вызова провайдера возвращает 403 и никуда дальше не отправляется. Классификатор запрещённых категорий подключается снаружи. Встроенного определителя запрещённого содержимого в репозитории нет.
