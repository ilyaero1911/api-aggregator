## Проверки

Локально прошли генерация Go/TS, Spectral без warnings, ESLint/TypeScript/go vet, Go race/serialization/handlers,16 migration checks на PostgreSQL18.6 PGlite,16 JSON Schema cases,official OpenAI SDK HTTP chat/SSE/Responses,5 исходных Python тестов иNext production build. Compose config проверен официальным CLI. Полный Docker run на Mac недоступен из-за отсутствия Engine; статус CI приводится отдельно после реального запуска.

Исходные данные: [миграции](../verification/migrations.json), [SSE benchmark](../architecture/benchmarks/sse-results.json). Benchmark — transport loopback, а не gateway p95;0 потерянных streams не означает0 lost usage. Handwritten financial core≥80% ещё не подтверждён, так как этот Go core отсутствует. Имеющийся Python ledger с known defects остаётся отдельно в baseline/204/205.
