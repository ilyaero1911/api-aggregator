# Отчёт

Собрал расчёт цены, очередь списаний, бюджеты ключей, бонусы, журнал и разбор ответов провайдеров. Проверка этих частей проходит.

Цена запроса берётся из версии прайса на момент вызова. Наценка складывается слоями: общая, провайдер, модель, клиент. Уже посчитанная сумма не меняется, когда прайс обновляют. Списание округляется вверх до копейки. Курс для валютной себестоимости записан в той же версии.

Событие usage ждёт в очереди, пока обработчик стоит. После запуска списывается один раз. Повтор того же запроса вторую проводку не создаёт. Если модель не ответила, резерв возвращается. Сначала тратится бонус, потом пакет, потом кошелёк. Бонус не идёт на запрещённую модель и сгорает по сроку. Пакет лежит отдельно, неизрасходованный остаток после списания остаётся.

У ключа есть лимит на период. Жёсткий лимит останавливает запрос, мягкий только отмечает 80% и 100%. Новый период обнуляет расход ключа. Баланс аккаунта от этого лимита не сгорает. Ответы баланса и ключа описаны: баланс, бонус, расход, лимит, остаток, сброс, уровень и лимит частоты.

Крупная корректировка ждёт второго подтверждения и остаётся в журнале действий. Повторное подтверждение платежа не зачисляет деньги второй раз. Возврат уменьшает баланс на ту же сумму. Промокод даёт бонус только новому клиенту. Реферальная ссылка не работает на себя, доля с пополнения приглашённого начисляется бонусом.

Сверка помечает расхождение от 0,5%. Финансовый отчёт складывает выручку, себестоимость и маржу. Правила антифрода такие: одноразовая почта, повторный отпечаток браузера, самоприглашение. Срабатывание видно списком.

Журнал отдаёт страницу только своей организации и фильтруется по модели, ключу и периоду. Без согласия текст запроса не пишется. С согласием он хранится в зашифрованном виде и удаляется по запросу. Выгрузка в CSV этого текста не содержит. По журналу считаются агрегаты, доля успешных ответов, p50 задержки и доля токенов. В публичный рейтинг попадает только приложение, которое само разрешило публикацию. Отправка следа повторяется, пока приёмник его не примет.

Схема таблицы requests для ClickHouse лежит в репозитории: разрез по месяцу, порядок по арендатору и времени, срок 13 месяцев. Сервер ClickHouse не поднимался, скорость вставки не замерял.

Ответы Gemini, DeepSeek, YandexGPT и GigaChat разбираются на фикстурах. У Gemini блокировка safety становится content_filter. У DeepSeek cache hit и cache miss считаются отдельно. YandexGPT и GigaChat помечены как обработка в РФ. Токен GigaChat обновляется после срока. Сравнение двух снимков каталога показывает новые, пропавшие и подорожавшие модели. Цена речи считается за символ, распознавания — за секунду. Боевые ключи провайдеров не вызывались.

Оценка числа токенов перед резервом считает слова. Сто тысяч слов укладываются быстрее 50 мс. Сверки с usage боевого провайдера нет: корпуса нет, поэтому эту задачу не закрываю.

Подпись вебхука платежа проверяется, повтор не зачисляет второй раз. Чек аванса собирается, счёт находится по номеру в назначении, акт считается по сумме, порог автопополнения решает, нужно ли пополнение. Боевой терминал, кассу, банк и ЭДО не подключал, эти задачи оставляю открытыми. Ряды регистраций, платящих и маржи считаются, сам дашборд не разворачивал. Эпики биллинга и аналитики не закрываю: живого месяца в проде и сверки с инвойсами провайдеров ещё нет.
